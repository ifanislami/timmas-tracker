## Findings

### HIGH (Hard Gate)

1. **R-02 — Em dash di UI**  
   Karakter `—` dipakai sebagai placeholder kosong di beberapa tempat: `AspirasiTab.jsx` (tindak lanjut), `MultimediaTab.jsx` (eng. rate / catatan / tanggal / link), `TodoTab.jsx` (hari event tanpa tanggal). Ganti dengan `-`, `(kosong)`, atau biarkan kosong dengan gaya muted.

2. **R-32 — Focus outline dihapus tanpa pengganti**  
   `.search-box input` memakai `outline: none` di `App.css` tanpa fokus kustom yang jelas. Input di dalam search box sulit terlihat saat Tab.

3. **R-32 — Modal tidak bisa ditutup Escape**  
   Semua modal (aspirasi, metric, clip, task, event) hanya tutup via klik backdrop / tombol X. Tidak ada handler `Escape` (dan tidak ada fokus trap sederhana).

4. **R-03 — Tap target di bawah 44px**  
   `.icon-btn` 32×32px; beberapa kontrol chip/close dan segmented kecil di mobile. Perbesar area sentuh (min ~44px) atau padding hit-area.

5. **R-27 — State loading/error belum lengkap**  
   Empty state sudah ada di tabel/kartu. Tidak ada loading state (meski data lokal hampir instan) dan error state UI untuk kegagalan bermakna (mis. import JSON rusak hanya `alert`, tanpa panel error yang bisa ditutup/diulang). Minimal: error banner untuk import + empty yang lebih actionable.

6. **R-37 / R-31 — Arah desain tidak tertulis saat UI dibuat**  
   UI ada sebelum `DESIGN.md`. Keputusan warna/radius/shadow tidak punya alasan tertulis. `DESIGN.md` baru dibuat (agent, mood operasional/tajam). Saat perbaikan, setiap keputusan mayor harus satu baris alasan dan mengikuti dial ENERGY 2 / RHYTHM 2 / MOTION 1.

7. **R-38 / R-23 — Sample aspirasi terlihat seperti data nyata**  
   `SAMPLE_ASPIRASI` di `App.jsx` memakai nama organisasi + nomor WA yang tampak real tanpa label contoh. Seed sebaiknya jelas bertanda contoh, atau dihapus agar empty state yang jujur muncul.

### MEDIUM (Purpose-Gate)

8. **R-01 — Radial glow / gradient background tanpa alasan tertulis**  
   `body` di `index.css` memakai dua radial gradient (emas + navy) mirip pola “colored glow background”. Header/button juga gradient navy. Izinkan hanya jika alasan hierarki/identitas ditulis (mis. navy = struktur, emas = aksen hemat); kurangi orb full-page jika tidak perlu.

9. **R-12 — Shadow hampir di setiap permukaan**  
   Shadow di header, main panel, tab aktif, modal, segmented aktif. Rasanya semua “mengambang”. Batasi elevation ke 1–2 lapisan (mis. header + modal saja).

10. **R-11 — Terlalu banyak bentuk pill**  
    Tab nav, chip topik, badge topik/status/prioritas semuanya `border-radius: 999px`. Kartu/input 10–14px. Samakan sistem radius: pill hanya untuk status yang memang “chip”, bukan default semua kontrol.

11. **R-06 — Header tabel uppercase + tracking**  
    `.data-table th` `text-transform: uppercase` + `letter-spacing`. Pola tipografi generik AI. Turunkan ke sentence case / small-caps ringan jika tetap ingin hierarki.

12. **R-04 — Lucide sebagai set default**  
    Hampir semua ikon dari Lucide (thin rounded). Ikonnya relevan (edit/hapus/arsip), tapi pilihan library belum punya alasan tertulis. Tetap Lucide boleh jika ditulis di `DESIGN.md` (tool internal, ikon familiar); atau ganti subset kritis dengan glyph yang lebih khas.

13. **R-14 — Stat card platform identik**  
    Tiga kartu IG/FB/X ukuran, padding, dan layout sama. Untuk perbandingan metrik ini bisa sah, tapi tulis alasan hierarki; pertimbangkan variasi ringan (mis. platform dengan entri 0 tampil lebih redup).

14. **R-29 — Warna status/platform menambah spektrum**  
    Navy + emas + banyak warna status + brand platform. Status/platform boleh semantik, tapi pastikan tidak dipakai sebagai dekorasi di luar konteksnya; jaga core 2–3 + 1 accent.

### LOW (Quality / Liveliness)

15. **R-20 / Liveliness — Identitas masih generik dashboard SaaS**  
    Komposisi header gradient + tab pill + kartu putih + shadow mudah tertukar dengan tool lain jika nama diganti. Perkuat motif navy/emas dari `DESIGN.md` (bukan menambah glow).

16. **Block 3 — Focal point & whitespace**  
    Per layar sering banyak kontrol setara (toolbar + topic manager + tabel). Tentukan satu fokus per view (mis. Aspirasi: tabel; Multimedia: ringkasan bulan) dan longgarkan spacing antar blok sesuai RHYTHM 2.

17. **R-21 — Theme**  
    Hanya light. Sesuai brief kerja siang/`DESIGN.md` (light default). Bukan wajib dark sekarang; catat sebagai sadar, bukan kelalaian. Jika nanti diminta toggle, kedua mode harus utuh (R-34).

## Yang sudah relatif baik (bukan finding)

- CTA spesifik produk (`Tambah Aspirasi`, `Input Mingguan`, `Export`/`Import`), bukan “Get Started”.
- Tidak ada testimonial palsu, FAQ template, fake marketing stats, atau glassmorphism massal.
- Empty state teks sudah ada di list/tabel.
- Navigasi tab mengarah ke konten yang benar-benar ada (R-24 OK).
- Interaksi utama (CRUD, filter, WA link, export/import) punya behavior nyata (R-26 sebagian besar OK).
